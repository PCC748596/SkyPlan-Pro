# Módulo: Constantes e Configurações (`constants.ts`)

## 🎯 O que este módulo faz?

O `constants.ts` define os valores imutáveis, dicionários de cores, listas estáticas de meses e dados inicializadores da aplicação.

## 📁 Localização no Repositório
`constants.ts`

## 🏷️ Categoria
*Constantes Globais*

---

## 🧠 Mapeamento Detalhado de Funções e Métodos

1. **`ACTIVITY_COLORS`**:
   - Dicionário com mapeamento visual de cores e gradientes Tailwind para cada tipo de código operacional (`VOO`, `FR`, `FS`, `SA`, `SIM`, `EXM`, `VAC`, `GS`).

2. **`generateInitialCrew()`**:
   - Cria o conjunto inicial de tripulantes com senioridades e funções predefinidas para demonstrar o sistema.

3. **`syncQualificationsWithSchedule()`**:
   - Utilitário que sincroniza os prazos de validade das carteiras dos tripulantes com as atividades agendadas.
